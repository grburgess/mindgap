# deep-research

Deep-think research **planning**. Brainstorming asks good questions;
second-brain knows what's already known; the mining modes know what isn't.
This skill wires them: plans are grounded in graph evidence and shaped by
real gaps, not naive clarifiers. It plans — it never executes the research.

## Dispatch

- **Inside a loop-system session → stop** (loops own their own protocol).
- **Build-shaped ask → hand back to superpowers:brainstorming.** The reverse
  entry is expected: brainstorming escalates HERE when an ask proves
  research-shaped ("we don't know enough to design this").
- Otherwise run the phases: GROUND → GAP → DIVERGE → [DEEP THINK] →
  CONVERGE → PAY BACK. Full protocol: `references/phases.md`.

## The phases, one line each

1. **GROUND** — second-brain RETRIEVE on the topic (enrich subgraph is the
   centerpiece).
2. **GAP** — mine `learn` + loop open-failures + contradictions → an
   evidence-cited gap list, shown to the user as the agenda.
3. **DIVERGE** — superpowers:brainstorming dialogue; every question cites
   evidence or a gap item.
4. **DEEP THINK** — *offer only*, when directions are contested or evidence
   thin: read-only scout fan-out + judge panel. Never auto-fired.
5. **CONVERGE** — `<project>/docs/research/YYYY-MM-DD-<topic>.md`: questions,
   hypotheses, method, evidence, measurable done-criteria, loop-shaped
   verdict. Approval-gated.
6. **PAY BACK** — register the plan in the graph (always), distill learnings,
   and if loop-shaped, offer loop-system INIT with §1–§2 pasted in.

## Boundaries

- Plans, never executes — execution is loop-system (multi-session) or a
  normal second-brain-wrapped task (one-shot).
- No new stores, no state files. Outputs: the plan doc + graph nodes only.
- DEEP THINK scouts are read-only; the Workflow opt-in rule is absolute.
- Loop handoff PASTES goal + done-criteria candidates into the INIT
  conversation; it never writes loop files — loop-system owns them.
