# second-brain

<!-- The loop-system ledger this skill reads lives at
     $MINDGAP_HOME/learning/loop-system/. This skill owns no ledger of its own. -->

The loop-system memory discipline — layered retrieve → work → distill — decoupled
from loop machinery, for one-shot tasks. The graph (mindgap) is the hub;
every substantive task starts by pulling what's already known and ends by paying
its learnings back. The returns compound. All graph writes obey the ingest
protocol in `AGENTS.md` — read it before writing.

## Dispatch — do this first

- **Inside a loop-system or meta-trainer session → stop.** Their RESUME/SESSION END
  already run this discipline; doubling it corrupts the loop's memory bookkeeping.
- **Task needs multi-session persistent state or a measurable done-gate → hand
  off to loop-system.** Never imitate loop machinery. No per-task state files,
  ever — a task that seems to need one is a loop wearing a disguise.
- **Mining asked for directly** ("find connections", "what next to learn",
  "enrich X from my notes") → `references/mining.md`, skip the cycle.
- Otherwise run the cycle: RETRIEVE → WORK → UPDATE.

## Stores — `~/second_brain/` (visible) + the graph (hidden)

```

  inbox/   drop zone — inbox-to-mindmap's default target; swept at UPDATE
  raw/     immutable archive — ingest MOVES files here (YYYY/topic/);
           source nodes carry url → the archived path

```

Scaffold missing dirs on first use (`mkdir -p`). The DB stays in
`~/.mindgap/` and is never touched by hand. Deliverables do NOT get an
`output/` dir — they stay in their repos; the graph indexes them (see UPDATE).

## RETRIEVE (task start) — protocol: `references/retrieval.md`

Five layers, top-down: global learnings → project ledger → task-adjacent loop
STATEs → graph (`mine enrich`) → `ctx/`. Context diet throughout: inline what is
relevant, never everything. Bump `used:/last:` on any global row that informs a
decision.

## WORK

Normal execution. Keep the graph in reach — `find`/`context` for specifics,
`enrich` when a subtopic opens up.

## UPDATE (task end) — protocol: `references/update.md`

Three moves, none skipped:

1. **Distill learnings** — one destination per learning, tiered gates: project
   reach writes direct, global reach goes through a verifier + user gate.
2. **Register deliverables** — every artifact produced (deck, report, doc,
   page) becomes a graph node (`type=page`, tag `artifact`, `url` → file path).
3. **Sweep `~/second_brain/inbox/`** — files present → offer `inbox-to-mindmap`.

## MAINTAIN (on request, not per task) — `references/mining.md`

- **enrich** — RWR-ranked relevant subgraph for grounding a topic (read-only).
- **learn** — ranked learning frontier: thin spots, stubs (read-only).
- **connect** — guarded latent-link candidates; adjudicate, then gated
  write-back.
